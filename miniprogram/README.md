## 导入与预览

1. 下载这个分支的仓库 ZIP 并解压（或下载 Actions 的 `wechat-miniprogram` 产物）。
2. 微信开发者工具 → 小程序 → 导入，**项目目录选择 `miniprogram/`**，不要选择仓库根目录。
3. AppID 使用 `wx3b755ea7217f2cc0`，基础库选择 3.4.0 或以上。代码已生成，不用安装 npm、构建 npm 或配置云开发。
4. 点击编译查看页面，点击预览扫码在手机上验证。主包和照片分包自动包含在项目内。

游客转盘、自定义菜单、日历文字及待办不需要后台服务。日历照片是本地资源，首次查看对应照片时由微信下载分包。没有网络时展示本地备用画面。

## 功能与账号

- 餐食/咖啡转盘、编辑与恢复菜单：2～10 项，每项最多 8 个字符，等概率随机选择。
- 90 条日历轮换、历史日期、经典全文、微信原生分享日期、生成图片、预览及保存相册。
- 今天可以新增、完成或删除待办；往日待办只读。
- 天气与手动城市搜索；获取失败可重试，不阻塞本地功能。
- 游客数据保存在当前小程序设备；登录后缓存按账号隔离，菜单和待办与 H5 同步。
- H5 浏览器游客数据与小程序游客数据属于不同设备存储，不会自动互相迁移。登录同一邮箱账号后才能同步。
- 首次导入游客数据需要选择，已有云端菜单保留、待办追加。退出后恢复小程序游客数据。
- 网络失败时未上传修改保留在本机。回到小程序、重新联网或点击刷新同步重试；跨设备使用需刷新。
- 注册后在邮箱点击确认链接，再返回小程序登录。忘记密码在邮件链接打开的 H5 页面设置新密码，再返回小程序；不支持微信一键登录。

## 后续与 H5 同步

在仓库根目录运行：

```sh
npm install --no-save --package-lock=false sharp@0.34.3
node scripts/build-miniprogram.cjs
```

脚本从 H5 生成 `generated/` 核心逻辑、目录、来源指纹及压缩照片分包；不要手工编辑生成文件。**H5 新增 UI 或业务流程仍需同步适配原生页面**，构建脚本不会把 DOM 页面自动转成 WXML。修改账号服务地址时同时核对 `config.js` 和后台域名。

CI 检查生成内容是否与 H5 一致、菜单和账号规则、原生页面行为、请求格式、JS 语法和包体，并使用 `miniprogram-compiler@0.2.3` 包装的 WXML/WXSS 编译器检查模板与样式；通过后上传 `wechat-miniprogram` 产物。编译器检查不代替最新微信开发者工具运行。主包和每个照片分包低于 2 MB，总包低于 20 MB。

## 发布前真机验收

1. 编译无报错；转盘在 2/6/10 个选项下指针和结果一致，保存菜单并重启后仍在。
2. 查看今日与历史日历，连续换日期、断网及重新联网；照片不能串日期。跨北京时间午夜检查今日待办。
3. 生成诗句/长故事图片，检查长文字和日期无裁切；预览、允许/拒绝/取消相册保存均有正确反馈。
4. 转发日历给另一微信账号，打开后日期一致。朋友圈分享受微信单页模式限制，应在普通打开方式中继续完整交互。
5. 在真实后台配置合法域名，手机实测 IP 天气、城市搜索、刷新天气。
6. 邮箱注册并实际收到邮件，确认后登录；同一账号在 H5 和小程序修改菜单/待办并分别刷新。
7. 导入游客数据，确认已有云端菜单未覆盖、重复导入待办不重复；退出恢复游客记录，换另一账号数据隔离。
8. 断网修改，再联网上传；有未同步修改时退出并重新登录，检查队列仍可上传。验证真实数据库 RLS 不允许读取其他账号数据。

本环境没有微信开发者工具或手机，Node 模拟平台测试不能代替上述验收。代码交付不代表已上传、提交审核或上线。
